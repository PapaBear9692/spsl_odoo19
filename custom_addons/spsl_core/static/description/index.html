SPSL Core

Foundation Module for SPSL Business Applications

This module provides the core infrastructure for Smart Printing Service Limited's Odoo implementation, including:

  • Approval Engine - Configurable multi-level approval workflows
  • Audit Trail - Comprehensive change tracking and logging
  • Notification System - Event-driven notifications via multiple channels
  • Commission Engine - Flexible commission calculation and aggregation
  • Multi-Branch Support - Data isolation across operating units
